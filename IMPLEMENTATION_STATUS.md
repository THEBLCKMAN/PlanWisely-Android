## Remaining setup before production

1. Apply and review the SQL migration against the target Supabase project; set the browser URL/key.
2. Deploy the five Edge Functions, configure provider/service/cron secrets, and schedule the agent as described in [SUPABASE_SETUP.md](SUPABASE_SETUP.md).
3. Configure Auth email/redirect settings and SMTP; add the intended admin account and complete TOTP setup.
4. Configure real guardian verification for under-18 users and have the operator approve privacy/POPIA terms and provider retention settings.
5. Test account isolation with two student accounts and the admin account; test the web deployment and build/install an APK in Android Studio.
